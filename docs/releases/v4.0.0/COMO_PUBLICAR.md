# Publicar FlowDetect 4.0.0 no GitHub

1. Abra https://github.com/kaua-ananiass/FlowDetect/releases/new.
2. Em **Tag**, digite `v4.0.0` e escolha criar a tag.
3. Em **Target**, selecione a branch `release/v4.0.0`. Ela contém as versões do Studio e da extensão usadas nos arquivos desta entrega.
4. No título, coloque **FlowDetect 4.0.0 — crie automações com IA**.
5. Copie o conteúdo de `NOVIDADES.md` para **Release notes**.
6. Na descrição, abaixo de **Veja o assistente trabalhando**, remova o comentário de instrução e deixe o cursor na linha em branco. Clique no clipe **Attach files** ou arraste `FlowDetect-4.0.0-IA-demo.mp4` para o campo da descrição. Aguarde o upload terminar. O GitHub insere o endereço que vira o player; use **Preview** para conferir.
7. Na área inferior **Attach binaries**, anexe:
   - `FlowDetect.Studio_4.0.0_x64-setup.exe`
   - `FlowDetect-para-Chrome-v0.2.96.zip`
   - `SHA256SUMS.txt`
8. Escolha **Latest**, confira o vídeo e os arquivos e clique em **Publish release**.

O vídeo otimizado tem menos de 1 MB e conserva a demonstração completa de aproximadamente 16 segundos. Use-o na descrição para evitar o limite de upload de vídeos de contas gratuitas. O arquivo original em Downloads permanece intacto.

**Vídeo na descrição** cria o player. Colocar o MP4 apenas em **Attach binaries** disponibiliza um download, mas não equivale a incluir a demonstração no texto da release.

Para revisar depois: abra a release → ícone de lápis **Edit** → ajuste texto/anexos → **Update release**.
